# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

- `npm run dev` — runs Next.js (turbopack) and Slice Machine concurrently. Next.js on `:3000`, Slice Machine on its own port.
- `npm run next:dev` — Next.js only (skip Slice Machine).
- `npm run slicemachine` — Slice Machine UI only.
- `npm run build` / `npm start` — production build and serve.
- `npm run lint` — ESLint (Next.js config).
- `npm run format` — Prettier write across the repo.

No test suite is configured.

## Architecture

Next.js 15 (App Router, React 19, Tailwind v4) site backed by **Prismic** as the CMS, with content modeled through **Slice Machine**.

### Content flow
- `src/prismicio.ts` creates the Prismic client. The repository name comes from `NEXT_PUBLIC_PRISMIC_ENVIRONMENT` or `slicemachine.config.json`. Route resolvers map `type: "page"` with `uid: "home"` to `/` and all other pages to `/:uid`. Production uses `force-cache` with a `"prismic"` tag; dev revalidates every 5s.
- `src/app/page.tsx` fetches the `home` page UID; `src/app/[uid]/page.tsx` handles all other pages via `generateStaticParams` (excludes `home`). Both render a `SliceZone` using the `components` map from `src/slices/index.ts`.
- `src/app/layout.tsx` fetches the single `settings` document and passes it to `HeaderWrapper` / `FooterWrapper`. It also mounts `PrismicPreview`, global effects (`CursorDot`, `Welcome`, `PageFade`), and GA.
- Preview + revalidate + contact endpoints live in `src/app/api/{preview,exit-preview,revalidate,contact}`. The preview/exit-preview routes are generated by the Prismic adapter — do not edit.
- `src/app/sitemap.ts` generates the sitemap from Prismic pages.
- `src/app/slice-simulator/page.tsx` is used by Slice Machine for isolated slice previews — do not edit.

### Slices and custom types
- Slice models and components live under `src/slices/<SliceName>/` (one folder per slice, with `index.tsx` as the React component and `model.json` as the Prismic model). `src/slices/index.ts` is **auto-generated by Slice Machine — do not hand-edit**; it wires slice API IDs to dynamic imports.
- Custom types live under `customtypes/` (`page`, `settings`). Types generated from these models are in `prismicio-types.d.ts` (auto-generated).
- To add/modify slices or custom types, use Slice Machine (`npm run slicemachine`) rather than editing generated files directly.

### Shared UI / lib
- `src/lib/` holds app-wide components and utilities (header/footer + wrappers, navigation, `PageFade`, `SectionDotsNav`, `HyphenatedHeadline`, morphing icons, `page-utils.ts`, etc.). These are imported by layout, pages, and slices; they are **not** Prismic-managed.
- The `[uid]` page conditionally mounts `<SectionDotsNav>` when `page.data.navigation` is set on the Prismic document.
- `HyphenatedHeadline` uses `hypher` + `hyphenation.en-us` (see `src/types/hypher.d.ts` for the shim).

### Conventions
- Path alias `@/*` → `src/*` (see `tsconfig.json`).
- Metadata in `[uid]/page.tsx` falls back to the `home` page's meta fields; canonical URL base is `NEXT_PUBLIC_SITE_URL` (defaults to `https://www.ie-brand.com`).
- Tailwind v4 via `@tailwindcss/postcss`; global styles in `src/app/globals.css`.
